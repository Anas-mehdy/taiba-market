# ماركت طيبة - Tayba Market 🛒

منصة كتالوج إلكتروني حديثة ومتكاملة لماركت وبقالية بيع بالتجزئة، تتيح للزبائن تصفح العروض اليومية المصورة وكتالوج المنتجات، واختيار الأصناف وإرسال الفاتورة والطلبية مباشرة إلى واتساب صاحب المتجر مع لوحة تحكم إدارية شاملة للمخزون والطلبات والإحصائيات.

---

## ✨ المميزات الرئيسية:

### 🛍️ واجهة المتجر والزبائن:
- **الصفحة الرئيسية (العروض اليومية):** عرض بوسترات وبانرات التخفيضات والعروض اليومية مع ميزة تكبير الصور وملء الشاشة.
- **صفحة المنتجات (الكتالوج الشامل):** كتالوج مقسم للأقسام مع بحث فوري وشبكة منتجات ثنائية وإضافة سلسة للسلة.
- **شريط تنقل سفلي ثابت (Bottom Navigation Bar):** تنقل فوري وسريع بين العروض، المنتجات، وسلة المشتريات.
- **شريط السلة العائم:** إشعار حي بعدد المواد المضافة والمجموع وزر إتمام الطلب.
- **صفحة إتمام الطلب (`/checkout`):** مراجعة الفاتورة وإدخال معلومات التوصيل مع إرسال مباشر إلى واتساب.

### ⚙️ لوحة تحكم الإدارة (`/admin`):
- **إدارة الطلبات:** متابعة الطلبيات المعلقة والمؤجلة، تعديل الفواتير، وتجميع البضائع من الرفوف، وطباعة فواتير A4 أو إيصالات حرارية 80mm POS.
- **إدارة العروض والبانرات (`/admin/banners`):** رفع ونشر وحذف بوسترات العروض اليومية.
- **إدارة المنتجات والأقسام:** إضافة وتعديل وترتيب المنتجات بالسحب والإفلات وتخصيص شارات العروض.
- **إدارة المخزون (`/admin/inventory`):** تتبع كميات المستودع مع خصم تلقائي فوري عند الطلب.
- **الإحصائيات والأرشيف (`/admin/statistics`):** كشف المبيعات، الفلاتر الزمنية، وتصدير التقارير.
- **دليل الزبائن (`/admin/customers`):** قائمة بأسماء وأرقام الزبائن لتسهيل المتابعة.
- **إعدادات المتجر والواتساب:** تخصيص رقم الهاتف المستلم للطلبات واسم المتجر.

## 🛠️ التقنيات المستخدمة:
- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Database & Storage:** Supabase (PostgreSQL + RLS + Triggers)
- **Icons:** Lucide React
- **PDF & Canvas:** jsPDF, html2canvas-pro

---

## 🚀 البدء والتشغيل:

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إعداد المتغيرات البيئية:
قم بإنشاء ملف `.env.local` بناءً على `.env.example`:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
```

### 3. إعداد قاعدة البيانات (Supabase):
قم بنسخ وتشغيل محتوى ملف `schema.sql` في SQL Editor الخاص بـ Supabase.

### 4. إعداد Storage Buckets:
أنشئ مجلدين عامين (Public Buckets) في Supabase Storage:
- `product-images`
- `banner-images`

### 5. تشغيل خادم التطوير:
```bash
npm run dev
```
